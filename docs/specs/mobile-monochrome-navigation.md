# Mobile Monochrome Navigation

## Goal

统一移动端视觉与导航：恢复可靠的深浅主题，采用黑白灰主配色，简化悬浮操作，并将连接状态整合到主题筛选抽屉。

## Users And Scenarios

- 用户在移动端切换黑色深色主题与白色浅色主题。
- 用户从右下角展开连接和发布操作。
- 用户打开主题筛选时同时查看当前连接状态。
- 用户仅切换接收消息的 Text/Hex 显示方式，不改变发送内容。

## Requirements

- 提供黑、白两套主题，首次默认跟随系统，用户选择后持久化。
- 页面主体只使用黑、白、灰；成功、警告、错误允许保留必要状态色。
- 清理移动组件中绕过主题系统的固定浅色和靛蓝样式。
- Text/Hex 控件移入连接配置，设置随连接配置保存。
- Text/Hex 仅控制接收消息显示，不修改原始日志、导出内容、发布 Payload 或发送编码。
- 移动端悬浮按钮关闭时贴在右侧边框，显示为紧凑半圆胶囊；点击后平滑展开连接与发布操作。
- 悬浮按钮不使用持续循环动画，展开期间保持清晰点击区域和安全区间距。
- 移除移动端主内容顶部的独立连接状态栏。
- 在左侧主题筛选抽屉顶部显示连接状态、Broker 地址、重连状态及连接/断开操作。
- 主题筛选抽屉支持关闭按钮、点击外部、向左滑动、Escape 和 Android Back 关闭。
- 抽屉内部选择主题时保持打开，便于连续多选。
- 桌面端现有布局和连接状态展示保持不变。

## Not Included

- 不增加第三套主题或自定义颜色编辑器。
- 不改变 MQTT Payload 的发送格式或编码。
- 不改变订阅、重连和消息存储逻辑。
- 不加入持续形变或装饰性动画。

## Acceptance Criteria

- 360px 至 430px 视口下，黑白主题均无固定浅色残留和横向溢出。
- 重启后保留用户选择的主题；未选择时响应系统主题。
- Text/Hex 切换后仅接收消息显示变化，原始数据、导出和发送结果不变。
- 悬浮按钮关闭时贴边且不遮挡主要内容，展开后两个操作均可访问。
- 连接状态仅在移动端主题筛选抽屉显示，桌面布局不变。
- 点击抽屉外部或完成一次有效向左滑动均能关闭抽屉。
- Android Back 每次只关闭最上层界面。
- `npm.cmd run verify` 与现有 MQTT 定向测试通过。
